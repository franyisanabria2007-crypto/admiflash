# Pedidos Flash — Estructura para Android

Copia el contenido de `pedidos-flash-admin/` dentro de tu proyecto Android:
- **Android WebView:** `app/src/main/assets/pedidos-flash-admin/`
- **Capacitor / Cordova:** `www/`

## Archivos incluidos
- `index.html`: Interfaz base enlazada a los recursos locales.
- `css/styles.css`: Estilos personalizados, animaciones y marcadores.
- `catalogo/catalogo-produ.js`: Catálogo base inicializado en `window.CATALOGO_PRODU_TXT`.
- `js/admin-app.js`: Configuración de Tailwind, navegación de pestañas y renderizado inicial.
- `img/`: Carpeta para colocar las imágenes locales de productos.
